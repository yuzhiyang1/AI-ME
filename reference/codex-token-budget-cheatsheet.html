不是摘要压缩，而是 Agent 管理外部记忆后的上下文窗口轮换。

主流程

→

→
new_context
→

→

三类状态

临时：Messages切窗后不自动带回
持久：Notes / History一个可写，一个只读
重建：World State规则、工具、权限、环境

恢复索引

Agent name哪个 Agent 的历史
Window ID哪个上下文窗口
Item ID窗口里的哪条事实

公开配置示例

6144 tokens接近边界时提醒
16384 tokensnotes + 切窗兜底缓冲
1 MB / note单个笔记文件上限
失败边界：忘记写 notes 会损失工作记忆；History 是最终一致；功能仍处于 UnderDevelopment，服务端实现未全部开源。
