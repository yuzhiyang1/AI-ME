# Skill 使用与验证说明

## 使用

将 `examples/skills/code-review` 整个目录复制到工作区的 `.agents/skills/` 下。
文件须采用 UTF-8 编码，`SKILL.md` 顶部 YAML 包含 `name` 与 `description`。
个人目录默认是 `~/.agents/skills`；环境变量 `AIME_SKILL_ROOTS` 可指定个人 Skill 根列表，Windows 用分号分隔。
项目来源优先，同名其他来源保留准确引用以供手动选择。

会话输入框下方点击 Skill，可搜索、启停、固定或选择。选择后插入 `/skill:<准确引用>`，继续输入任务并发送即可。
客户端侧栏提供常驻「技能」独立页面：顶部搜索、双列已安装目录和真实来源分类。无会话时展示个人来源，进入会话后展示该会话的项目与个人来源。支持刷新、展开更多，以及点选查看详情、启停、固定和使用；运行期间仍可浏览。输入框旁保留快捷选择弹窗。
也支持 `/skill:code-review`；名称重名时按项目来源优先解析。
`disable-model-invocation: true` 表示仅允许用户明确选择，不进入自动目录和搜索。
固定只影响展示优先级，不突破目录预算。

自动调用时，模型先收到受预算限制的简介，再调用 `skill_search` 和 `skill_read`。
Skill 原文通过用户资料或工具结果传入模型；路径由本机读取器处理。
工具卡片展示自动读取的版本及分页状态，原始指令保留用户的显式引用。
脚本不会因读取 Skill 自动执行，后续执行继续走原有权限与工具账本。

## 已实施边界

- 目录使用保守 UTF-8 字节计数，上限 `min(模型容量 × 2%, 4000)`，并根据完整请求的剩余预算缩减。
- 搜索最多 8 个结果，采用名称/描述关键词匹配及中文单字匹配，准确引用优先；没有语义向量检索或同义词保证。
- 主文和附件分页按模型容量的八分之一分配，每页 1400 至 12000 字节；`complete=false` 时模型必须继续读取。已分页正文直接送入模型，完整请求仍经过上下文预算检查。主文件或单个附件最大 256000 字节；若当前模型需要超过 24 页，首次读取就提示换大窗口模型或拆分手册，避免读到中途耗尽默认 32 次请求预算。
- 每轮最多显式选择 8 项、加载 16 个不同 Skill。超限返回明确错误；选择中存在失效项时整轮失败，不静默跳过。
- 首次发现冻结目录版本；首次读取核对主文件版本并保存正文。已经读取的资源在同一 Run 内重读快照，不混入修改后的源文件。
- 目录、正文快照、偏好与已读引用保存在 SQLite 的 `skill_state` 表。换窗保留已读引用，正文可再次分页加载。
- 附件必须位于 Skill 根内；绝对路径、父目录逃逸及链接路径被拒绝。个人 Skill 读取不扩展其他执行工具权限。
- 引用由根路径哈希及相对位置组成；移动来源会产生新引用，旧偏好不会自动迁移。
- 扫描每次有总条目上限；未实现文件监听缓存、快照过期清理或语义检索。UI 获取完整目录，按每页 20 项展示筛选结果。

这些限制是本次实际实现；设计文档中的独立显式加载卡片、详细成本统计和真实模型长任务评估仍是后续完善项。

## 本轮代码审查修复

- 两个界面入口都对显式引用进行 URL 编码；服务端保留原始 ref 匹配兼容，并支持解码后的引用，因此目录空格和百分号不再破坏选择。已有偏好和快照身份不变。
- 按模型容量扩大正文页，已分页 Skill 结果不再套一层产物读取；过多分页的资源首次读取即明确拒绝。请求总上限和完整请求预算检查仍然有效。
- 技能页打开时跳过不可见的回答动画等待；若动画收尾已经在等待，也主动释放回调，避免已完成的任务仍显示忙碌。
- 回归场景覆盖带空格/百分号引用、60 KB 正文配 32K 窗口、250 KB 正文配 128K 窗口、过小窗口首次拒绝，以及技能页内等待任务完成后立即选用 Skill。
